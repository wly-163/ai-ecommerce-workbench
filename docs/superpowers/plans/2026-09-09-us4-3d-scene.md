# US-4 3D 场景 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 前端首页变成可旋转的 3D 品类立方体场景；输入查询后调用现有工作流 API，按返回商品的 `category` 点亮对应立方体。

**Architecture:** 颜色映射抽成纯函数便于 Vitest；`executeWorkflow` 只负责 HTTP；`ProductScene` 只负责 R3F；`App` 管查询条与状态。Playwright 拦截 API，CI 不启后端。

**Tech Stack:** React 19、Vite 5、`three`、`@react-three/fiber` v9、`@react-three/drei`、Vitest、Playwright Chromium。

## Global Constraints

- 不改后端；沿用 `POST /api/v1/workflows/execute`，`stream: false`
- `VITE_API_URL` 默认 `http://localhost:8000`
- 不新增路由 / Zustand / shadcn
- 分支 `feature/4-3d-scene`，不直接改 main
- commit 说明中文、不要 `Co-authored-by: Cursor`
- 立方体品类固定：外套 / 配饰 / 下装；点亮色 `#3b82f6` / `#f59e0b` / `#22c55e`；暗态 `#64748b`
- 失败保留上一帧颜色；空 query 不发请求
- jsdom 不测 WebGL 像素

export const CATEGORIES = ["外套", "配饰", "下装"] as const;
export type Category = (typeof CATEGORIES)[number];

export const DIM_COLOR = "#64748b";
export const CATEGORY_COLORS: Record<Category, string> = {
  外套: "#3b82f6",
  配饰: "#f59e0b",
  下装: "#22c55e",
};

export function highlightCategories(products: { category: string }[]): Set<Category> {
  const hits = new Set<Category>();
  for (const p of products) {
    if ((CATEGORIES as readonly string[]).includes(p.category)) {
      hits.add(p.category as Category);
    }
  }
  return hits;
}

export function cubeColor(category: Category, highlighted: Set<Category>): string {
  return highlighted.has(category) ? CATEGORY_COLORS[category] : DIM_COLOR;
}
```

export type WorkflowProduct = {
  id: string;
  name: string;
  price: number;
  category: string;
};

export type WorkflowExecuteResult = {
  query: string;
  products: WorkflowProduct[];
  recommendation: string;
};

const API_URL = import.meta.env.VITE_API_URL ?? "http://localhost:8000";

export async function executeWorkflow(query: string): Promise<WorkflowExecuteResult> {
  const resp = await fetch(`${API_URL}/api/v1/workflows/execute`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ query, stream: false }),
  });
  if (!resp.ok) {
    throw new Error(`工作流请求失败: ${resp.status}`);
  }
  return resp.json() as Promise<WorkflowExecuteResult>;
}
```
